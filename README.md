# 🏡 Real Estate Website

A fully responsive and modern **Real Estate Website** built using **HTML5**, **Tailwind CSS**, and custom **CSS animations**. This project is ideal for realtors, property dealers, or real estate agencies looking to showcase properties online with a sleek and interactive interface.

---

## 📌 Project Overview

This static website is designed to highlight real estate listings, agent services, and contact forms. Built using Tailwind CSS utility classes, the site offers clean structure, fast performance, and smooth animations to enhance the user experience.

---

## 🎨 Features

- 🏘️ Elegant homepage showcasing properties
- 💬 Contact and inquiry sections
- 🎯 Animated call-to-action buttons
- 🖼️ Property cards with hover effects
- 🌀 Smooth scroll animations using Tailwind's keyframes
- 📱 Fully responsive (mobile, tablet, desktop)

---

## 🛠️ Technologies Used

- **HTML5** – for semantic structure
- **Tailwind CSS** – for utility-first styling
- **Font Awesome** – for icons (optional)
- **Custom CSS Animations** – for interactive transitions
